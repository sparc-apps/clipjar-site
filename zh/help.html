内容如何进入历史记录

Mac

ClipJar 会关注剪贴板：你拷贝（⌘C）的所有内容都会自动出现在历史记录中。来自已排除应用（默认是密码管理器）的拷贝会被忽略。菜单栏图标 →“暂停历史记录”：开启期间拷贝的内容不会被保存（剪贴板本身照常工作）。

iPhone 和 iPad

iOS 不允许应用监视剪贴板。可通过顶部的“粘贴”按钮、共享 → ClipJar、ClipJar 键盘或快捷指令自动化来添加内容。暂停按钮（在“外观”中打开）会在打开 ClipJar 时停止检查剪贴板；“粘贴”和“共享”照常可用。

粘贴

Mac

按 ⌥⌘V（可在设置中更改）打开面板。↑↓ 选择，Return 粘贴，⇧Return 粘贴纯文本，⌘1…⌘9 按编号粘贴。←→ 折叠和展开分组（或文件列表），⌥↑⌥↓ 在分组内移动条目。面板会在你输入的文本光标旁打开；如果应用不提供光标位置，则在鼠标指针旁打开。

iPhone 和 iPad

轻点一项即可拷贝，然后像平常一样在任意应用中粘贴。长按查看更多：以纯文本拷贝、操作、移动、删除。

预设

Mac

预设是一组功能：决定 ClipJar 识别哪些内容、提供哪些操作。“简单”只有拷贝和粘贴，“日常”增加截屏和图片中的文字，其他预设面向开发、财务和内容创作。可在“设置”→“功能”或菜单栏图标 →“预设”中选择。Mac 的预设与 iPhone 和 iPad 的相互独立。你自己的预设（Pro）会同步到你的其他 Mac，而当前选中的预设在每台 Mac 上各自独立。

iPhone 和 iPad

预设决定你能看到哪些按钮和菜单项。“简单”只有列表：轻点项目即可拷贝。“标准”和“完整”增加固定、移动、编辑、筛选、操作和标签。可在“设置”→“外观”→“预设”中选择。iPhone 和 iPad 的预设与 Mac 的相互独立。你自己的预设（Pro）会同步到你的其他 iPhone 和 iPad，而当前选中的预设在每台设备上各自独立。

固定、移动、删除

MaciPhone 和 iPad

固定的项目始终在顶部，不会因历史上限或保留期限被删除。箭头可在组内移动项目。删除的项目可用“撤销”恢复（Mac 上为 ⌘Z）。分组会整体移动；重启后顺序保持不变。在 Mac 上，⌥⌘↑ 可将条目或分组移到顶部。开启 Pro 同步后，固定条目的顺序在你所有的设备上保持一致。

标签、废纸篓和多选

Mac

右键点按项目 → 标签，为它设置颜色（🔴🟠🟡🟢🔵🟣⚪️）。标签会同步到你的其他设备。 删除的项目会进入废纸篓（顶部的🗑）：恢复、预览或永久删除。⌘Z 可撤销上一次删除。Pro 可在历史设置中关闭废纸篓。 ⌘-点按可标记多个项目；右键 → 全选 / 删除（N）。⌘⌫ 删除已标记项目。Esc 关闭窗口。

iPhone 和 iPad

长按项目 → 标签，为它设置颜色。标签会同步。 删除的项目会进入废纸篓（“编辑”旁的🗑）：轻扫可恢复或永久删除，长按可预览。Pro 可关闭废纸篓。 点按“编辑”，用圆圈选择项目，然后在底部点按 全选 / 删除（N）。设置 → 外观 → 预设 → 简单 可隐藏多余功能。

搜索和筛选

MaciPhone 和 iPad

输入即可搜索全部历史。筛选可只显示链接、代码、表格、图片、IBAN 等类型。

分组与按应用筛选

MaciPhone 和 iPad

⧉ 按钮可按 App、设备或类型对固定项目和最近项目分组：2 个及以上的项目合并为一行并显示数量。点按可展开，按 ← 收起。右键点按或轻扫分组，可将整组固定、取消固定或删除（删除的项目进入“最近删除”）。“App”筛选只显示某一个 App 的项目。搜索或筛选时不显示分组。

“卡片”视图

Mac

设置 → 外观 → 界面 → 卡片（Pro）：以卡片显示项目的紧凑窗口。点按卡片即可粘贴；⋯ 按钮或右键可固定、预览、粘贴为纯文本、识别文本、删除。顶部的 ⋯ 可设置粘贴时去除格式以及卡片上显示的内容。同步、保护、截屏和隔离剪贴板照常工作；预设和其他功能在标准界面中生效。随时可以切换回来。

最近删除

MaciPhone 和 iPad

删除的项目会进入“最近删除”（Pro），可以恢复或永久删除。整组删除的项目保留为一行，可一次恢复或删除，也可展开逐个处理。验证码和卡号到期后也会从废纸篓中移除。废纸篓只存在于内存中，退出 ClipJar 时清空；在“卡片”视图中只保留最后一次删除，用于撤销。

智能操作

MaciPhone 和 iPad

ClipJar 能识别你拷贝的内容并提供合适的操作：格式化 JSON、清理链接、修正用错键盘布局输入的文字、校验 IBAN、把收款信息拆分成字段。结果会成为新项目。

打开和编辑

Mac

右键 → 打开 / 编辑… 或 ⌘O。文本在编辑器中打开（⌘S 保存），图片在可缩放的预览中打开，文件用默认应用打开。表格和格式文本会以原始样式（颜色、字体、合并单元格）显示在白色页面上；调色板按钮可切换为主题颜色。

iPhone 和 iPad

轻点行中的铅笔按钮，或长按 → 打开 / 编辑。带格式的文本会保留粗体和斜体。表格和格式文本会以原始样式（颜色、字体、合并单元格）显示在白色页面上；调色板按钮可切换为主题颜色。

“打开方式”与标记

Mac

右键点按项目 →“打开方式”，即可在其他应用（文本编辑、预览、你的代码编辑器）中编辑它的副本。在那里按 ⌘S 存储，改动就会回到 ClipJar。Pro 功能。

iPhone 和 iPad

按住图片 →“标记”，可以绘图、添加文字或裁剪。轻点“完成”，编辑后的图片会替换同一位置的项目。Pro 功能。

ClipJar 键盘

iPhone 和 iPad

在任意应用中从历史粘贴：设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → ClipJar，允许完全访问，然后在 ClipJar 设置中打开访问。用 🌐 切换键盘。只显示文本，绝不显示验证码或卡号。

快捷指令自动化

iPhone 和 iPad

“Add to ClipJar”操作无需打开应用即可保存剪贴板。可设为轻点背面、操作按钮或个人自动化。

隐私

Mac

ClipJar 从不使用网络。磁盘上的历史已加密，密钥保存在钥匙串中。一次性验证码、卡号和个人证件号会被隐藏并很快删除。来自已排除应用的拷贝会被忽略。

iPhone 和 iPad

ClipJar 从不使用网络。设备上的历史已加密。一次性验证码、卡号和个人证件号会被隐藏并很快删除。通用剪贴板在你允许前保持关闭。在“隐私”中打开锁屏时清除，iPhone 锁定时会删除未固定的项目。

隐藏的验证码和卡号

MaciPhone 和 iPad

一次性验证码、卡号和个人证件号码会用圆点隐藏，并自动删除。要查看内容，请在项目菜单中选择“显示”。如果 ClipJar 隐藏了并非机密的内容（例如订单号），选择“不是机密”，它就会变成普通项目。

隔离剪贴板

Mac

Pro：“设置”→“隐私”→“隔离剪贴板”。列表中的每个应用（例如“终端”）都有自己的剪贴板：切换进去恢复它的剪贴板，离开则恢复你的共享剪贴板。在其中拷贝的内容只有你允许时才会存入历史，另需单独允许才会同步。隔离剪贴板绝不会通过 Apple 通用剪贴板传到 iPhone；此类应用打开期间在 iPhone 上拷贝的文本会进入共享剪贴板。需要在预设中打开此功能（功能）。 开启 Pro 同步后，此列表和“不记录这些应用的内容”列表会在你所有的 Mac 间共享。某台 Mac 上未安装的应用会在那里显示为“未在这台 Mac 上安装”。

iPhone 和 iPad

隔离剪贴板仅适用于 Mac：iOS 不会告诉应用当前打开的是哪个其他应用，因此 iPhone 和 iPad 上无法为每个应用提供单独的剪贴板。Mac 上隔离应用中拷贝的项目，只有在 Mac 上允许同步时才会到达 iPhone。

保留多久

MaciPhone 和 iPad

历史条数限制保存的数量；保留期限会在所选时间后删除未固定的项目。清空历史后可立即撤销。超过大小上限（图片和文本，在历史记录设置中）的项目不会被添加；过大的格式会以纯文本保存。

在你的设备之间同步

MaciPhone 和 iPad

Pro：打开“设置”→“同步”→“共享固定项目”，并在每台设备上选择 iCloud 云盘中的同一个文件夹和同一个密码。固定项目、标签和你自己的预设会加密保存在那里；ClipJar 本身从不联网。在“我的设备”中可以看到所有设备：可以停止接受某台设备的更改，或忘记旧设备。删除的项目会在所有设备上删除。你添加的格式和语言也会同步。你可以随时添加新设备：在新设备上用同一个文件夹和密码打开同步。长时间未同步的设备会被自动忘记（“设置”→“同步”→“长时间未同步的设备在此之后忘记”，默认 1 年）；如果它重新上线，你在其他设备上删除的项目只会保留在它上面。如果忘记密码，同步的副本将无法解密，但本地历史记录会保留。密码至少 8 个字符，开头和结尾不能有空格；拉丁字母在任何设备上都最容易输入。

自定义语言和格式

MaciPhone 和 iPad

语言：“设置”→“高级”→“创建模板”，翻译各行（help.* 行也会翻译本帮助），设置自己的 code 和 name，点按“重新载入”，然后在“外观”→“语言”中选择。号码格式：在“可识别的号码”中“创建模板”，修改后点按“重新载入”；“可识别的内容”列出 ClipJar 认识的全部内容。打开同步后，你的语言和格式会同步到其他设备。

迁移到另一台设备

MaciPhone 和 iPad

把设置导出为文件（可设密码），然后在另一台 Mac 或 iPhone 上导入，两者使用同一种文件。另一台设备没有的选项会保留下来，迁回时仍然有效。

还原设置

MaciPhone 和 iPad

“还原所有设置”（设置 → 高级）会恢复默认值。历史记录、固定项目、购买、同步和你自己的预设都会保留，“恢复之前的设置”可以找回旧设置。

Free 与 Pro

MaciPhone 和 iPad

Free：5 条历史、3 个固定、两个基本预设、基本操作，以及对验证码和卡号的完整保护。Pro：最多 1000 条、无限固定、全部预设及自定义预设、智能操作、收款信息、编辑、设备间同步、保存历史记录等。一次购买，所有设备通用，7 天试用。
