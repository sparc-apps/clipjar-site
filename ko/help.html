항목이 기록에 들어가는 방식

Mac

ClipJar는 클립보드를 지켜봅니다. 복사한 모든 것(⌘C)이 자동으로 기록에 나타납니다. 제외한 앱(기본값: 암호 관리 앱)에서 복사한 내용은 무시합니다. 메뉴 막대 아이콘 → ‘기록 저장 일시 정지’를 켜 두면 그동안 복사한 내용이 저장되지 않습니다(클립보드 자체는 평소처럼 작동합니다).

iPhone 및 iPad

iOS에서는 앱이 클립보드를 지켜볼 수 없습니다. 상단의 붙여넣기 버튼, 공유 → ClipJar, ClipJar 키보드 또는 단축어 자동화로 항목을 추가하세요. 일시 정지 버튼(모양에서 켜기)을 누르면 ClipJar를 열 때 클립보드를 확인하지 않습니다. 붙여넣기와 공유는 그대로 작동합니다.

붙여넣기

Mac

⌥⌘V(설정에서 변경 가능)로 패널을 엽니다. ↑↓ 선택, Return 붙여넣기, ⇧Return 일반 텍스트로 붙여넣기, ⌘1…⌘9 번호로 붙여넣기. ←→로 그룹(또는 파일 목록)을 접고 펼치며, ⌥↑⌥↓로 항목을 그룹 안에서 옮깁니다. 패널은 입력 중인 텍스트 커서 옆에 열립니다. 앱이 커서 위치를 알려 주지 않으면 마우스 포인터 옆에 열립니다.

iPhone 및 iPad

항목을 탭하면 복사되고, 평소처럼 아무 앱에나 붙여넣으면 됩니다. 길게 누르면 더 많은 기능: 일반 텍스트로 복사, 동작, 이동, 삭제.

프로필

Mac

프로필은 기능의 묶음입니다. ClipJar가 무엇을 인식하고 어떤 동작을 제안할지 정합니다. ‘간단’은 복사와 붙여넣기만, ‘일상’은 스크린샷과 이미지 속 텍스트를 더하고, 나머지 프로필은 개발, 재무, 콘텐츠 작업용입니다. 설정 → 기능 또는 메뉴 막대 아이콘 → 프로필에서 선택합니다. Mac 프로필은 iPhone·iPad 프로필과 별개입니다. 나만의 프로필(Pro)은 다른 Mac과 동기화되며, 선택한 프로필은 Mac마다 따로 유지됩니다.

iPhone 및 iPad

프로필에 따라 보이는 버튼과 메뉴 항목이 달라집니다. ‘간단’은 목록만 있어 항목을 탭하면 복사됩니다. ‘표준’과 ‘전체’는 고정, 이동, 편집, 필터, 동작, 레이블을 추가합니다. 설정 → 모양 → 프로필에서 선택합니다. iPhone·iPad 프로필은 Mac 프로필과 별개입니다. 나만의 프로필(Pro)은 다른 iPhone·iPad와 동기화되며, 선택한 프로필은 기기마다 따로 유지됩니다.

고정, 이동, 삭제

MaciPhone 및 iPad

고정한 항목은 항상 위에 있고 기록 한도나 보관 기간으로 지워지지 않습니다. 화살표로 그룹 안에서 이동합니다. 삭제한 항목은 실행 취소로 되돌릴 수 있습니다(Mac에서는 ⌘Z). 그룹은 통째로 이동하며, 순서는 다시 시작한 뒤에도 유지됩니다. Mac에서는 ⌥⌘↑로 항목이나 그룹을 맨 위로 옮깁니다. Pro 동기화를 켜면 고정 항목의 순서가 모든 기기에서 같습니다.

레이블, 휴지통, 여러 항목 선택

Mac

항목을 오른쪽 클릭 → 레이블로 색을 지정합니다(🔴🟠🟡🟢🔵🟣⚪️). 레이블은 다른 기기와 동기화됩니다. 삭제한 항목은 휴지통(상단 🗑)으로 갑니다: 복원, 미리보기, 영구 삭제. ⌘Z로 마지막 삭제를 취소합니다. Pro에서는 기록 설정에서 휴지통을 끌 수 있습니다. ⌘-클릭으로 여러 항목을 표시하고, 오른쪽 클릭 → 모두 선택 / 삭제 (N). ⌘⌫는 표시한 항목을 삭제합니다. Esc는 창을 닫습니다.

iPhone 및 iPad

항목을 길게 눌러 → 레이블로 색을 지정합니다. 레이블은 동기화됩니다. 삭제한 항목은 휴지통(편집 옆 🗑)으로 갑니다: 쓸어서 복원하거나 영구 삭제, 길게 눌러 미리보기. Pro에서는 휴지통을 끌 수 있습니다. 편집을 누르고 원으로 항목을 선택한 뒤 아래의 모두 선택 / 삭제 (N). 설정 → 모양 → 프로필 → 간단은 부가 기능을 숨깁니다.

검색과 필터

MaciPhone 및 iPad

입력하면 전체 기록을 검색합니다. 필터로 링크, 코드, 표, 이미지, IBAN 등만 볼 수 있습니다.

그룹 및 앱별 필터

MaciPhone 및 iPad

⧉ 버튼으로 고정 항목과 최근 항목을 앱, 기기 또는 유형별로 그룹화합니다. 2개 이상이면 개수가 표시된 한 줄이 되며, 클릭하거나 탭하면 펼쳐지고 ←로 접힙니다. 그룹을 오른쪽 클릭하거나 스와이프하면 모두 고정, 모두 고정 해제 또는 그룹 전체 삭제를 할 수 있습니다(삭제한 항목은 최근 삭제된 항목으로 이동). ‘앱’ 필터는 한 앱의 항목만 보여 줍니다. 검색하거나 필터를 적용하는 동안에는 그룹이 표시되지 않습니다.

‘카드’ 보기

Mac

설정 → 모양 → 인터페이스 → 카드(Pro): 항목을 카드로 보여 주는 작은 창. 카드를 클릭하면 붙여넣습니다. ⋯ 버튼이나 오른쪽 클릭으로 고정, 미리보기, 일반 텍스트로 붙여넣기, 텍스트 인식, 삭제를 할 수 있습니다. 위쪽 ⋯에서는 서식 없이 붙여넣기와 카드에 표시할 내용을 정합니다. 동기화, 보호, 스크린샷, 격리된 클립보드는 그대로 작동하며 프로필과 다른 기능은 표준 인터페이스에서 적용됩니다. 언제든 되돌릴 수 있습니다.

최근 삭제된 항목

MaciPhone 및 iPad

삭제한 항목은 ‘최근 삭제된 항목’(Pro)으로 이동하며 복원하거나 완전히 삭제할 수 있습니다. 통째로 삭제한 그룹은 한 줄로 남아 한 번에 복원하거나 삭제할 수 있고, 펼쳐서 항목을 하나씩 다룰 수도 있습니다. 코드와 카드 번호는 만료되면 휴지통에서도 사라집니다. 휴지통은 메모리에만 있으며 ClipJar를 종료하면 비워집니다. ‘카드’ 보기에서는 취소용으로 마지막 삭제만 보관됩니다.

스마트 동작

MaciPhone 및 iPad

ClipJar는 복사한 내용을 알아보고 알맞은 동작을 제안합니다: JSON 정리, 링크 정리, 잘못된 자판으로 입력한 글자 고치기, IBAN 확인, 송금 정보를 항목별로 나누기. 결과는 새 항목이 됩니다.

열기와 편집

Mac

오른쪽 클릭 → 열기 / 편집… 또는 ⌘O. 텍스트는 편집기(⌘S 저장), 이미지는 확대 가능한 미리보기, 파일은 기본 앱에서 열립니다. 표와 서식 있는 텍스트는 색, 글꼴, 병합된 셀 등 원본 스타일 그대로 흰 페이지에 열립니다. 팔레트 버튼을 누르면 테마 색으로 바뀝니다.

iPhone 및 iPad

행의 연필 버튼을 탭하거나 길게 눌러 → 열기 / 편집. 서식 있는 텍스트는 굵게와 기울임을 유지합니다. 표와 서식 있는 텍스트는 색, 글꼴, 병합된 셀 등 원본 스타일 그대로 흰 페이지에 열립니다. 팔레트 버튼을 누르면 테마 색으로 바뀝니다.

‘다음으로 열기’와 마크업

Mac

항목을 오른쪽 클릭 → ‘다음으로 열기’를 선택하면 다른 앱(텍스트 편집기, 미리보기, 코드 편집기 등)에서 사본을 편집할 수 있습니다. 그곳에서 ⌘S로 저장하면 변경 내용이 ClipJar에 반영됩니다. Pro 기능입니다.

iPhone 및 iPad

이미지를 길게 눌러 → ‘마크업’을 선택하면 그리기, 텍스트 추가, 자르기를 할 수 있습니다. ‘완료’를 탭하면 편집한 이미지가 같은 자리의 항목을 대체합니다. Pro 기능입니다.

ClipJar 키보드

iPhone 및 iPad

어느 앱에서나 기록에서 붙여넣기: 설정 → 일반 → 키보드 → 키보드 → 새로운 키보드 추가 → ClipJar, 전체 접근 허용 후 ClipJar 설정에서 접근을 켜세요. 🌐로 전환합니다. 텍스트만 보이며 코드나 카드는 나오지 않습니다.

단축어 자동화

iPhone 및 iPad

‘Add to ClipJar’ 동작은 앱을 열지 않고 클립보드를 저장합니다. 뒷면 탭, 동작 버튼 또는 개인용 자동화에 지정하세요.

개인정보 보호

Mac

ClipJar는 네트워크를 전혀 사용하지 않습니다. 디스크의 기록은 암호화되고 키는 키체인에 보관됩니다. 일회용 코드, 카드 번호, 개인 식별 번호는 숨겨지고 곧 삭제됩니다. 제외한 앱에서 복사한 내용은 무시합니다.

iPhone 및 iPad

ClipJar는 네트워크를 전혀 사용하지 않습니다. 기기의 기록은 암호화됩니다. 일회용 코드, 카드 번호, 개인 식별 번호는 숨겨지고 곧 삭제됩니다. 범용 클립보드는 허용하기 전까지 꺼져 있습니다. 개인정보 보호에서 잠금 시 지우기를 켜면 iPhone이 잠길 때 고정하지 않은 항목이 삭제됩니다.

숨겨진 코드와 카드

MaciPhone 및 iPad

일회용 코드, 카드 번호, 개인 식별 번호는 점으로 가려지고 자동으로 삭제됩니다. 내용을 보려면 항목 메뉴에서 ‘보기’를 선택합니다. 비밀이 아닌 것(예: 주문 번호)이 가려졌다면 ‘비밀 아님’을 선택하면 일반 항목이 됩니다.

격리된 클립보드

Mac

Pro: 설정 → 개인정보 보호 → 격리된 클립보드. 목록의 각 앱(예: 터미널)은 자체 클립보드를 가집니다. 전환하면 그 클립보드가, 벗어나면 공유 클립보드가 돌아옵니다. 그곳에서 복사한 내용은 허용한 경우에만 기록에 저장되고, 별도로 허용해야만 동기화됩니다. 격리된 클립보드는 Apple 유니버설 클립보드를 통해 iPhone으로 절대 전송되지 않으며, 이런 앱이 열려 있는 동안 iPhone에서 복사한 텍스트는 공유 클립보드로 갑니다. 프로필에서 이 기능을 켜야 합니다(기능). Pro 동기화를 켜면 이 목록과 ‘이 앱들에서는 기록 안 함’ 목록이 모든 Mac에서 공유됩니다. 어떤 Mac에 설치되지 않은 앱은 그곳에서 ‘이 Mac에 설치되어 있지 않음’(으)로 표시됩니다.

iPhone 및 iPad

격리된 클립보드는 Mac에서만 사용할 수 있습니다. iOS는 다른 어떤 앱이 열려 있는지 앱에 알려 주지 않으므로 iPhone과 iPad에서는 앱별 클립보드가 불가능합니다. Mac의 격리된 앱에서 복사한 항목은 Mac에서 동기화를 허용한 경우에만 iPhone에 도착합니다.

보관 기간

MaciPhone 및 iPad

기록 개수로 보관할 항목 수를 제한하고, 보관 기간으로 고정하지 않은 항목을 정한 시간 후에 지웁니다. 기록 지우기는 바로 취소할 수 있습니다. 크기 제한(이미지와 텍스트, 기록 설정)을 넘는 항목은 추가되지 않으며, 너무 큰 서식은 일반 텍스트로 저장됩니다.

기기 간 동기화

MaciPhone 및 iPad

Pro: 설정 → 동기화 → ‘고정 항목 공유’를 켜고, 모든 기기에서 같은 iCloud Drive 폴더와 같은 암호를 선택합니다. 고정 항목, 레이블, 나만의 프로필이 그곳에 암호화되어 저장되며, ClipJar 자체는 인터넷에 연결하지 않습니다. ‘내 기기’에서 모든 기기를 볼 수 있고, 특정 기기의 변경을 받지 않거나 오래된 기기를 잊을 수 있습니다. 삭제한 항목은 모든 기기에서 삭제됩니다. 직접 추가한 형식과 언어도 동기화됩니다. 새 기기는 언제든지 추가할 수 있습니다. 그 기기에서 같은 폴더와 암호로 동기화를 켜세요. 오랫동안 동기화되지 않은 기기는 자동으로 지워집니다(설정 → 동기화 → ‘동기화되지 않는 기기를 지우기까지’, 기본값 1년). 그 기기가 다시 돌아오면 다른 기기에서 삭제한 항목은 그 기기에만 남습니다. 암호를 잊으면 동기화된 사본을 복호화할 수 없지만 로컬 기록은 그대로 남습니다. 암호는 8자 이상이며 앞뒤에 공백이 없어야 합니다. 어느 기기에서나 입력하기 쉬운 영문자를 권장합니다.

직접 추가하는 언어와 형식

MaciPhone 및 iPad

언어: 설정 → 고급 → 템플릿 생성에서 줄을 번역하고(help.* 줄은 이 도움말도 번역합니다), 직접 code와 name을 정한 뒤 다시 불러오기를 누르고 모양 → 언어에서 선택하세요. 번호 형식: 인식되는 번호에서 템플릿 생성 후 수정하고 다시 불러오기를 누르세요. 인식되는 항목에서 ClipJar가 아는 모든 것을 볼 수 있습니다. 동기화를 켜면 직접 추가한 언어와 형식이 다른 기기에도 전달됩니다.

다른 기기로 옮기기

MaciPhone 및 iPad

설정을 파일로 내보내고(원하면 암호와 함께) 다른 Mac이나 iPhone에서 가져오세요. 둘 다 같은 파일을 씁니다. 다른 기기에 없는 옵션도 되돌아갈 때를 위해 보존됩니다.

설정 재설정

MaciPhone 및 iPad

‘모든 설정 재설정’(설정 → 고급)은 기본값으로 되돌립니다. 기록, 고정 항목, 구입, 동기화, 나만의 프로필은 유지되며, ‘이전 설정으로 되돌리기’로 예전 설정을 복원할 수 있습니다.

Free와 Pro

MaciPhone 및 iPad

Free: 기록 5개, 고정 3개, 기본 프로필 2개, 기본 동작, 코드·카드 완전 보호. Pro: 최대 1000개, 무제한 고정, 모든 프로필과 나만의 프로필, 스마트 동작, 송금 정보, 편집, 기기 간 동기화, 기록 저장 등. 모든 기기에서 쓰는 1회 구입, 7일 체험.
