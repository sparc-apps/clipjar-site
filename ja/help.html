履歴に入る仕組み

Mac

ClipJar はクリップボードを見守ります。コピー（⌘C）したものは自動で履歴に入ります。除外したアプリ（初期設定ではパスワード管理アプリ）からのコピーは記録しません。メニューバーのアイコン→「履歴を一時停止」をオンにすると、その間コピーしたものは保存されません（クリップボード自体は通常どおり使えます）。

iPhone と iPad

iOS ではアプリがクリップボードを見守ることはできません。上部の「ペースト」ボタン、共有 → ClipJar、ClipJar キーボード、またはショートカットのオートメーションで追加します。一時停止ボタン（「外観」でオン）を使うと、ClipJar を開いたときにクリップボードを確認しなくなります。「ペースト」と「共有」は通常どおり使えます。

ペースト

Mac

⌥⌘V（設定で変更可）でパネルを開きます。↑↓ で選択、Return でペースト、⇧Return でプレーンテキスト、⌘1…⌘9 で番号指定ペースト。←→ でグループ（またはファイル一覧）を折りたたみ・展開、⌥↑⌥↓ で項目をグループ内で移動できます。パネルは入力中のテキストカーソルの近くに開きます。アプリがカーソル位置を伝えない場合は、マウスポインタの近くに開きます。

iPhone と iPad

項目をタップするとコピーされ、いつも通りどのアプリにもペーストできます。長押しでその他：プレーンテキストでコピー、アクション、移動、削除。

プロファイル

Mac

プロファイルは機能の組み合わせです。ClipJar が何を認識し、どのアクションを表示するかが決まります。「シンプル」はコピーと貼り付けだけ、「日常」はスクリーンショットと画像内のテキストを追加し、そのほかのプロファイルは開発・経理・コンテンツ制作向けです。「設定」→「機能」またはメニューバーのアイコン→「プロファイル」で選びます。Mac のプロファイルは iPhone・iPad のプロファイルとは別です。自分で作ったプロファイル（Pro）はほかの Mac と同期され、選択中のプロファイルは Mac ごとに異なります。

iPhone と iPad

プロファイルで、表示するボタンとメニュー項目が決まります。「シンプル」はリストだけで、項目をタップするとコピーされます。「標準」と「フル」では、固定・移動・編集・フィルタ・アクション・ラベルが加わります。「設定」→「外観」→「プロファイル」で選びます。iPhone・iPad のプロファイルは Mac のプロファイルとは別です。自分で作ったプロファイル（Pro）はほかの iPhone・iPad と同期され、選択中のプロファイルはデバイスごとに異なります。

固定・移動・削除

MaciPhone と iPad

固定した項目は常に上に表示され、履歴の上限や保存期間で消えることはありません。矢印でグループ内を移動します。削除した項目は「取り消す」で戻せます（Mac では ⌘Z）。グループはまとめて移動します。並び順は再起動後も保たれます。Mac では ⌥⌘↑ で項目やグループを一番上へ移動できます。Pro の同期をオンにすると、ピン留めした項目の並び順はすべてのデバイスで同じになります。

ラベル、ゴミ箱、複数選択

Mac

項目を右クリック → ラベルで色を付けます（🔴🟠🟡🟢🔵🟣⚪️）。ラベルは他のデバイスと同期されます。 削除した項目はゴミ箱（ヘッダーの🗑）に入ります：復元、プレビュー、完全に削除。⌘Zで最後の削除を取り消せます。Proでは履歴設定でゴミ箱をオフにできます。 ⌘クリックで複数の項目に印を付け、右クリック →「すべて選択」/「削除（N）」。⌘⌫で印を付けた項目を削除。Escでウインドウを閉じます。

iPhone と iPad

項目を長押し → ラベルで色を付けます。ラベルは同期されます。 削除した項目はゴミ箱（「編集」の横の🗑）に入ります：スワイプで復元または完全に削除、長押しでプレビュー。Proではゴミ箱をオフにできます。 「編集」をタップし、丸で項目を選び、下の「すべて選択」/「削除（N）」。設定 → 外観 → プロファイル →「シンプル」で余分な表示を隠せます。

検索とフィルタ

MaciPhone と iPad

入力すると履歴全体を検索します。フィルタでリンク、コード、表、画像、IBAN などだけを表示できます。

グループとアプリ別フィルタ

MaciPhone と iPad

⧉ ボタンで、固定項目と最近の項目をアプリ・デバイス・種類別にグループ化できます。2件以上で件数付きの1行になり、クリックまたはタップで展開、← で折りたたみます。グループを右クリックまたはスワイプすると、すべて固定・固定解除・グループごと削除ができます（削除した項目は「最近削除した項目」へ）。「アプリ」フィルタは1つのアプリの項目だけを表示します。検索中やフィルタ中はグループを表示しません。

「カード」表示

Mac

設定 → 外観 → インターフェイス → カード（Pro）：項目をカードで表示するコンパクトなウインドウ。カードをクリックするとペーストします。⋯ ボタンまたは右クリックで、ピン留め、プレビュー、プレーンテキストとしてペースト、テキスト認識、削除。上部の ⋯ で、書式なしでのペーストとカードに表示する内容を設定できます。同期、保護、スクリーンショット、分離クリップボードはそのまま動作し、プロファイルとその他の機能は標準インターフェイスで有効になります。いつでも元に戻せます。

最近削除した項目

MaciPhone と iPad

削除した項目は「最近削除した項目」（Pro）に入り、復元するか完全に削除できます。まとめて削除したグループは1行のまま残り、一度に復元・削除するか、展開して1件ずつ扱えます。コードとカード番号は期限が来るとゴミ箱からも消えます。ゴミ箱はメモリ上だけにあり、ClipJar を終了すると空になります。「カード」表示では取り消し用に最後の削除だけが保持されます。

スマートアクション

MaciPhone と iPad

ClipJar はコピーした内容を判別し、合ったアクションを提案します：JSON の整形、リンクのクリーンアップ、別のキー配列で入力した文字の修正、IBAN の確認、振込先情報の分割など。結果は新しい項目になります。

開く・編集

Mac

右クリック → 開く / 編集… または ⌘O。テキストはエディタ（⌘S で保存）、画像は拡大できるプレビュー、ファイルは既定のアプリで開きます。表とフォーマット付きテキストは、元のスタイル（色、フォント、結合セル）のまま白いページに表示されます。パレットのボタンでテーマの色に切り替えられます。

iPhone と iPad

行の鉛筆ボタンをタップするか、長押し → 開く / 編集。書式付きテキストは太字と斜体を保ちます。表とフォーマット付きテキストは、元のスタイル（色、フォント、結合セル）のまま白いページに表示されます。パレットのボタンでテーマの色に切り替えられます。

「このアプリで開く」とマークアップ

Mac

項目を右クリック→「このアプリで開く」で、コピーをほかのアプリ（テキストエディット、プレビュー、コードエディタなど）で編集できます。そこで ⌘S で保存すると、変更が ClipJar に戻ります。Pro 機能です。

iPhone と iPad

画像を長押し→「マークアップ」で、描き込み、テキストの追加、切り取りができます。「完了」をタップすると、編集した画像が同じ位置の項目と置き換わります。Pro 機能です。

ClipJar キーボード

iPhone と iPad

どのアプリでも履歴からペースト：設定 → 一般 → キーボード → キーボード → 新しいキーボードを追加 → ClipJar、フルアクセスを許可し、ClipJar の設定でアクセスをオンにします。🌐 で切り替え。表示はテキストのみで、コードやカードは出ません。

ショートカットのオートメーション

iPhone と iPad

「Add to ClipJar」アクションはアプリを開かずにクリップボードを保存します。背面タップ、アクションボタン、個人用オートメーションに割り当てられます。

プライバシー

Mac

ClipJar はネットワークを一切使いません。ディスク上の履歴は暗号化され、鍵はキーチェーンに保管されます。ワンタイムコード、カード番号、個人番号は隠され、すぐに削除されます。除外したアプリからのコピーは記録しません。

iPhone と iPad

ClipJar はネットワークを一切使いません。端末上の履歴は暗号化されます。ワンタイムコード、カード番号、個人番号は隠され、すぐに削除されます。ユニバーサルクリップボードは許可するまでオフです。「プライバシー」で画面ロック時の消去をオンにすると、iPhone のロック時に固定していない項目が削除されます。

隠されたコードとカード

MaciPhone と iPad

ワンタイムコード、カード番号、個人番号は点で隠され、自動的に削除されます。内容を見るには、項目のメニューで「表示」を選びます。秘密ではないもの（注文番号など）が隠されたときは、「秘密ではない」を選ぶと通常の項目になります。

分離クリップボード

Mac

Pro：「設定」→「プライバシー」→「分離クリップボード」。リストの各アプリ（例：ターミナル）は専用のクリップボードを持ちます。切り替えるとそのクリップボードが戻り、離れると共有クリップボードが戻ります。そこでのコピーは許可した場合のみ履歴に保存され、さらに別の許可がある場合のみ同期されます。分離クリップボードが Apple のユニバーサルクリップボードで iPhone に送られることはありません。こうしたアプリを開いている間に iPhone でコピーしたテキストは共有クリップボードに入ります。プロファイルでこの機能をオンにする必要があります（機能）。 Pro の同期をオンにすると、このリストと「これらのアプリからは記録しない」のリストはすべての Mac で共有されます。ある Mac にインストールされていないアプリは、そこでは「この Mac にはインストールされていません」と表示されます。

iPhone と iPad

分離クリップボードは Mac 専用です。iOS はほかにどのアプリが開いているかをアプリに知らせないため、iPhone や iPad でアプリごとのクリップボードは実現できません。Mac の分離アプリでコピーした項目は、Mac で同期を許可した場合にのみ iPhone に届きます。

保存期間

MaciPhone と iPad

履歴の件数で保存数を制限し、保存期間で固定していない項目を指定時間後に削除します。履歴の消去は直後なら取り消せます。サイズの上限（画像とテキスト、履歴の設定）を超える項目は追加されません。大きすぎる書式はプレーンテキストとして保存されます。

デバイス間の同期

MaciPhone と iPad

Pro：「設定」→「同期」→「固定項目の共有」をオンにし、すべてのデバイスで同じ iCloud Drive のフォルダと同じパスワードを選びます。固定項目、ラベル、自分で作ったプロファイルはそこに暗号化して保存され、ClipJar 自体はインターネットに接続しません。「マイデバイス」にはすべてのデバイスが表示され、特定のデバイスからの変更を受け取らないようにしたり、古いデバイスを削除したりできます。削除した項目はすべてのデバイスから削除されます。独自の形式と言語も同期されます。 新しいデバイスはいつでも追加できます。そのデバイスで同じフォルダとパスワードで同期をオンにしてください。長い間同期していないデバイスは自動的に削除されます（「設定」→「同期」→「同期しないデバイスを削除するまでの期間」、初期設定は1年）。そのデバイスが戻ってきても、他のデバイスで削除した項目はそのデバイスにだけ残ります。パスワードを忘れると同期したコピーは復号できませんが、ローカルの履歴は残ります。パスワードは8文字以上で、先頭と末尾にスペースを入れないでください。どのデバイスでも入力しやすい半角英数字がおすすめです。

独自の言語と形式

MaciPhone と iPad

言語：「設定」→「詳細」→「テンプレートを作成」で行を翻訳し（help.* の行はこのヘルプも翻訳します）、独自の code と name を設定して「再読み込み」を押し、「外観」→「言語」で選択します。番号の形式：「認識される番号」で「テンプレートを作成」し、編集して「再読み込み」を押します。「認識される番号」の一覧で ClipJar が認識できるものをすべて確認できます。同期をオンにすると、独自の言語と形式が他のデバイスにも届きます。

別の端末へ移す

MaciPhone と iPad

設定をファイルに書き出し（パスワードも可）、別の Mac や iPhone で読み込みます。両方とも同じファイルです。相手の端末にないオプションも戻すときのために保持されます。

設定のリセット

MaciPhone と iPad

「すべての設定をリセット」（設定 → 詳細）で初期設定に戻ります。履歴、固定項目、購入、同期、自分で作ったプロファイルはそのままで、「以前の設定に戻す」で元の設定を復元できます。

Free と Pro

MaciPhone と iPad

Free：履歴 5 件、固定 3 件、基本プロファイル 2 つ、基本アクション、コードとカードの完全な保護。Pro：最大 1000 件、固定無制限、すべてのプロファイルと独自のプロファイル、スマートアクション、振込先情報、編集、デバイス間の同期、履歴の保存など。すべてのデバイスで使える買い切り、7 日間のお試し付き。
